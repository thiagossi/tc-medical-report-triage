# Triagem de Laudos — Tech Challenge Fase 3 (FIAP MLET)

Classificador de texto (NLP) que lê um laudo médico e classifica a urgência
em **normal / atenção / urgente**, servido via API REST (FastAPI) em Docker,
com CI/CD no GitHub Actions, retreino orquestrado pelo Airflow e
monitoramento com Prometheus + Grafana.
